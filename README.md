# SurgiGuard

**Reliable Intraoperative Video Segmentation**

Motion-aware temporal control for a fixed segmentation model.

[![KDD 2026](https://img.shields.io/badge/KDD-2026-2a7c78?style=flat-square)](https://doi.org/10.1145/3770855.3818851)

SurgiGuard adds temporal control to frame-wise segmentation: align recent predictions, estimate a reliable history reference, and adapt the update where current evidence indicates change. Its monitoring layer tracks mask dynamics throughout a video stream.

## Architecture

| Component | Responsibility | Code |
|:---|:---|:---|
| **Motion alignment** | Warp historical probabilities into the current frame; qualify correspondence using consistency and bounds. | [Alignment](src/surgiguard/temporal/alignment.py) |
| **Temporal control** | Combine the current prediction with a robust history reference through a per-pixel gate. | [Controller](src/surgiguard/temporal/controller.py) |
| **Stream monitoring** | Isolate stream state, validate time order, and report flicker, drift, and area-growth trends. | [Service](src/surgiguard/service/api.py) · [Monitoring](src/surgiguard/monitoring/) |

## Quick start

```bash
git clone https://github.com/inhalc/surgiguard.git
cd surgiguard
python -m pip install -e ".[app,dev]"
streamlit run app/streamlit_app.py
```

The demo uses synthetic data and requires no model weights.

<details>
<summary><strong>Connect a segmenter, launch the API, or run tests</strong></summary>

Supply a Python callable accepting a BGR frame and returning a two-dimensional probability map in `[0, 1]`:

```bash
python scripts/run_video.py procedure.mp4 --predictor my_model:predict_probability
```

Launch the single-process API:

```bash
uvicorn surgiguard.service.api:app --reload
```

Run the core checks:

```bash
python -m pytest -q
python -m ruff check .
```

</details>

## Research

**Controlling Prediction Dynamics for Reliable Intraoperative Segmentation**

Jiutao Zhou, Xiaoyang Li, Yuhao Zhang, Xiaoqian Peng, Weiguang Qu, Peirong Ma, and Yanhui Gu. · **KDD 2026**

[Read the paper](https://doi.org/10.1145/3770855.3818851) · [Citation metadata](CITATION.cff)

| Publication metric | nnU-Net baseline | Proposed method |
|:---|---:|---:|
| Dice ↑ | 0.62 ± 0.03 | **0.73 ± 0.02** |
| Centroid drift ↓ | 5.8 ± 0.6 px | **2.6 ± 0.4 px** |
| Flicker rate ↓ | 0.21 ± 0.03 | **0.09 ± 0.01** |
| Trend-prompt lead time ↑ | 1.0 ± 0.3 s | **2.2 ± 0.4 s** |

<sub>Publication-reported results: segmentation metrics from Table 1; lead time from the internal trend-prompt evaluation in Table 2, using nnU-Net trend as the baseline. These measurements are separate from the synthetic demo.</sub>

The paper evaluates 300 intraoperative sequences and three public surgical benchmarks. Full comparison conditions and protocols are given in the publication.
